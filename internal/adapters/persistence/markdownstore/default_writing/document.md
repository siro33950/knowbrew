# Distilled Document Writing Rules

## Information order

- When the Template does not prescribe an order, organize information by the reader's questions and the relationships between ideas, not by Knowledge ID, Type, or input order.
- Keep each section focused on one coherent question.
- Do not scatter the same content across multiple sections.

## Headings

- Make each heading identify the specific content explained in its section.
- Avoid headings such as `Overview`, `Details`, or `Other` when they do not identify the content.
- Do not create a heading for a single sentence or item.
- Add a heading only when the content moves to a different coherent subject; do not fragment the document excessively.

## Presentation formats

- Explain history, rationale, and relationships between concepts in paragraphs.
- Present parallel items, conditions, alternatives, and procedures as bullet lists.
- Use a table when comparing multiple attributes of the same set of items.
- Use prose when a list or table would obscure the relationship between ideas.
- Do not compose the entire document as bullet lists.
